Student Record and Academic Management System

A Python-based system for managing student academic records using built-in Python data structures.

🎯 Features

- Add student records
- Search students by roll number
- Update student information
- Delete student records
- Display all students
- Calculate average marks
- Find highest scorer
- List students by department
- Count total students

🧰 Technologies

- Python 3
- Strings
- Lists
- Tuples
- Sets
- Dictionaries

🚀 How to Run

Clone the repository:

git clone YOUR_GITHUB_REPOSITORY_URL

Run the program:

python student_management.py

📊 Data Structures

Data Structure| Usage
String| Names, departments, contact details
List| Subjects, marks, attendance
Tuple| Roll number, registration number, DOB
Set| Student clubs and unique values
Dictionary| Complete student records

🧪 Testing

The project tests valid inputs, duplicate records, invalid inputs, empty records, searching, updating, deleting, average calculation, and student counting.

🎓 Learning Outcomes

This project demonstrates Python data structures, functions, CRUD operations, searching, calculations, input validation, testing, and documentation.
